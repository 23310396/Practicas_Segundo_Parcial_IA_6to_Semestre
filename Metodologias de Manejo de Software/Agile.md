# Agile / Ágil

## ¿Qué es?

Agile es una metodología iterativa y flexible para manejar proyectos de software. A diferencia de Waterfall, no espera hasta el final para entregar todo el sistema completo. En Agile, el proyecto se divide en partes pequeñas que se van desarrollando y entregando poco a poco.

Su idea principal es adaptarse a los cambios, trabajar en equipo y recibir retroalimentación constante del cliente o usuario.

## ¿Para qué sirve?

Sirve para proyectos donde los requisitos pueden cambiar durante el desarrollo.

Es muy útil en aplicaciones móviles, páginas web, plataformas digitales, sistemas comerciales y productos de software donde el cliente puede ir ajustando funciones conforme ve avances.

También sirve cuando se quiere entregar valor rápido, aunque el sistema todavía no esté terminado al cien por ciento.

## ¿Cómo se aplica?

Se aplica trabajando en ciclos cortos de desarrollo:

1. Se identifican las funciones principales del sistema.
2. Se priorizan las funciones más importantes.
3. Se desarrolla una parte funcional del software.
4. Se prueba esa parte.
5. Se entrega al cliente o usuario.
6. Se recibe retroalimentación.
7. Se mejora el producto en la siguiente iteración.

El proceso se repite hasta completar el sistema.

## Ejemplo

Un equipo desarrolla una aplicación de pedidos de comida. En lugar de construir toda la app de una sola vez, primero entrega una versión básica con registro de usuarios y menú digital.
Después agrega el carrito de compras. Luego integra pagos en línea. Más adelante añade rastreo del pedido y calificaciones del restaurante.
Cada avance se prueba con usuarios reales. Si los usuarios dicen que el carrito es confuso, el equipo lo mejora en la siguiente versión.
Este proyecto se adapta bien a Agile porque puede cambiar conforme se reciben comentarios.
