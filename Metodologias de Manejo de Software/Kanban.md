# Kanban

## ¿Qué es?

Kanban es una metodología visual para administrar el trabajo en proyectos de software. Utiliza un tablero dividido en columnas que representan el estado de las tareas.

Las columnas más comunes son:

- Por hacer
- En desarrollo
- En pruebas
- Terminado

Cada tarea se coloca en una tarjeta y se va moviendo conforme avanza el trabajo.

## ¿Para qué sirve?

Sirve para visualizar claramente el flujo de trabajo y evitar que el equipo tenga demasiadas tareas abiertas al mismo tiempo.

Es muy útil en mantenimiento de software, soporte técnico, corrección de errores, actualizaciones constantes y proyectos donde llegan tareas nuevas todo el tiempo.

También ayuda a identificar cuellos de botella, es decir, partes del proceso donde se acumulan demasiadas tareas.

## ¿Cómo se aplica?

Se aplica creando un tablero Kanban. Cada tarea del proyecto se representa con una tarjeta.

Ejemplo de columnas:

| Por hacer | En desarrollo | En pruebas | Terminado |
|---|---|---|---|
| Crear login | API de usuarios | Carrito de compras | Registro completo |
| Corregir error de pago | Mejorar búsqueda | Validar reportes | Página principal |

El equipo mueve las tarjetas conforme avanza el trabajo.

También se pueden establecer límites de trabajo en proceso. Por ejemplo, no permitir más de tres tareas al mismo tiempo en la columna “En desarrollo”. Esto evita saturar al equipo.

## Ejemplo

Un equipo mantiene una tienda en línea. Todos los días pueden aparecer errores, mejoras o solicitudes nuevas.
Algunas tareas son:
- Corregir error en pago con tarjeta.
- Mejorar el buscador de productos.
- Actualizar el diseño del carrito.
- Agregar opción de cupones.
- Optimizar carga de imágenes.
Cada tarea se coloca en el tablero Kanban. Cuando un desarrollador comienza una tarea, la mueve a “En desarrollo”. Cuando termina, la pasa a “En pruebas”. Si funciona correctamente, se mueve a “Terminado”.
Kanban funciona bien porque el trabajo es continuo y no necesariamente se organiza en sprints.
